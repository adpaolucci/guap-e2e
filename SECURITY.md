# Security Policy

## Scope

`guap-e2e` is the deterministic fixture, Tier 1–4 verification, and R4 Clean-Room compliance harness for the GUAP ecosystem. It operates exclusively on local workspaces and synthetic offline fixtures with zero network daemons or external telemetry.

## Reporting Vulnerabilities

Report suspected security issues or R4 rule bypasses privately via GitHub Security Advisories on `https://github.com/adpaolucci/guap-e2e`.
